Hobgoblin v2.3.1 improves cross-platform terminal workflows, Windows and WSL interoperability, and repository automation. This release adds configurable Windows internal shells, richer terminal clipboard actions, a Windows `hob` launcher, safer Git and SSH handling, and macOS Computer Use permission controls.

## Highlights

- **Choose the right Windows internal shell:** Select automatic detection, WSL, PowerShell, or Command Prompt for new internal terminals while preserving the active working directory when possible.
- **Copy and paste across terminal workflows:** Copy terminal selections from context menus, paste text through xterm, paste supported clipboard images into terminals, and keep standard Windows edit accelerators working as expected.
- **Open projects with `hob` on Windows:** The installer adds the launcher to the current user's `PATH`, so `hob .` opens or imports the current directory directly from PowerShell or Command Prompt.
- **Work across Windows and WSL paths:** Repository paths are translated safely between Windows and WSL contexts, with clearer project-opening behavior and native Windows OpenSSH fallback when required.
- **Make Git operations safer and more responsive:** Status reads use bounded concurrency, complete remote alignment can recover repositories that need a full synchronization, and repository/worktree refresh behavior is more consistent.
- **Manage macOS Computer Use permissions:** macOS users can inspect and request Screen Recording and Accessibility permissions from Hobgoblin settings when those capabilities are available.
- **Polish the workspace experience:** Project repository scrolling, file-tree refreshes, terminal navigation, and localized `hob` command guidance receive focused usability improvements.

## Linux Server Mode

`Hobgoblin-2.3.1-linux-source.tar.gz` contains the tracked Web/Server sources, configuration, licenses, and deployment scripts required for Linux Server Mode.

Install Node.js 24+ and Bun 1.3.11, then run:

```sh
tar -xzf Hobgoblin-2.3.1-linux-source.tar.gz
cd Hobgoblin-2.3.1
./scripts/serve-systemd.sh
```

Because the deployment archive does not contain Git metadata, use `./scripts/serve-systemd.sh update --no-pull` after replacing its files with a newer archive.

## Unsigned builds

The desktop builds and Android APK are unsigned.

- **macOS:** If Gatekeeper blocks the app, right-click it, choose **Open**, and confirm. You can also run `xattr -dr com.apple.quarantine /Applications/Hobgoblin.app` after installation.
- **Windows:** SmartScreen may warn about the installer. Continue only if you trust this GitHub Release source. WSL with a Unix-like terminal environment is recommended.
- **Android:** The APK must be signed before installation.
