Hobgoblin v2.2.1 expands workspace-centered parallel development across desktop, browser, Android, and Linux Server Mode. This release makes multi-repository work easier to organize, keeps mobile and tmux sessions recoverable, and adds a focused Linux source deployment archive.

## Highlights

- **Multi-repository workspaces:** Configure independent repositories under one workspace root for shared files and root-level terminals without erasing each repository's Git boundary.
- **Branch workspaces:** Create one branch-focused context across selected repository worktrees, choose each member's base branch, materialize optional copied or linked dependencies, and work from either the shared root or one member.
- **Coordinated Git workflows:** Run ordered member commit, pull, push, merge-in, and merge-out operations with explicit progress. A failed member stops the sequence while completed member results remain visible and intact.
- **Refined workspace navigation:** Repository rows, Branch workspace creation controls, file-area behavior, terminal activity, and merge-conflict AI handoff keep the active repository and worktree context clear.

## Android and tmux

- Initialize SSH access and diagnose saved Hosts, browse remote Projects and Worktrees, and perform bidirectional worktree merges from Android.
- Retain, close, reconnect, and reopen mobile terminal sessions while keeping foreground terminal continuity and saved port forwards.
- Explicitly create or reconnect deterministic `hobgoblin-v1-*` sessions on project-scoped tmux servers from desktop or browser workflows.
- Use the Android tmux catalog to discover current-protocol Hobgoblin sessions on project-scoped and compatibility default servers alongside ordinary default tmux sessions, then reopen an existing session without creating a replacement.

## Linux Server Mode

`Hobgoblin-2.2.1-linux-source.tar.gz` contains only the tracked Web/Server sources, configuration, licenses, and deployment scripts required for Linux Server Mode. It excludes Android, Electron desktop sources, tests, planning documents, dependencies, and generated output.

Install Node.js 24+ and Bun 1.3.11, then run:

```sh
tar -xzf Hobgoblin-2.2.1-linux-source.tar.gz
cd Hobgoblin-2.2.1
./scripts/serve-systemd.sh
```

Because the deployment archive does not contain Git metadata, use `./scripts/serve-systemd.sh update --no-pull` after replacing its files with a newer archive.

## Unsigned builds

The desktop builds and Android APK are unsigned.

- **macOS:** If Gatekeeper blocks the app, right-click it, choose **Open**, and confirm. You can also run `xattr -dr com.apple.quarantine /Applications/Hobgoblin.app` after installation.
- **Windows:** SmartScreen may warn about the installer. Continue only if you trust this GitHub Release source.
- **Android:** The APK must be signed before installation.
