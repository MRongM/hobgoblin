Hobgoblin v2.3.0 expands branch workspace automation, Windows and WSL interoperability, and secure remote terminal control. This release adds safer multi-repository synchronization, first-class detached-HEAD worktree handling, a streamlined operation console, and opt-in Telegram terminal input while preserving explicit confirmation and terminal authority boundaries.

## Highlights

- **Plan branch workspace operations in one place:** The redesigned operation console brings repository dependencies, creation and removal plans, and execution feedback into a clearer single flow.
- **Synchronize repositories safely at scale:** Concurrent fetch and batch Git actions now cover full remote alignment, upstream creation during push, and explicit confirmation before destructive alignment.
- **Manage detached-HEAD worktrees:** Detached worktrees remain visible and usable across status, history, changes, terminal, editor, and removal workflows without inventing a branch identity.
- **Work naturally with Windows and WSL projects:** Hobgoblin resolves native Windows Git explicitly, preserves WSL working directories, applies Git network settings inside WSL, and improves terminal and external-application process launching.
- **Build Windows releases faster from WSL:** The new build helper can package and optionally install the primary Windows application through the Windows-native toolchain while reusing validated Electron caches.
- **Send authorized terminal input through Telegram:** An opt-in receiver accepts fresh, bounded, single-line input from explicitly allowlisted numeric user IDs in the configured chat and delivers it only to the most recently focused terminal that still owns input authority.
- **Improve Windows terminal clipboard behavior:** Terminal keyboard handling preserves ordinary copy and paste behavior while respecting active terminal applications.

## Linux Server Mode

`Hobgoblin-2.3.0-linux-source.tar.gz` contains the tracked Web/Server sources, configuration, licenses, and deployment scripts required for Linux Server Mode.

Install Node.js 24+ and Bun 1.3.11, then run:

```sh
tar -xzf Hobgoblin-2.3.0-linux-source.tar.gz
cd Hobgoblin-2.3.0
./scripts/serve-systemd.sh
```

Because the deployment archive does not contain Git metadata, use `./scripts/serve-systemd.sh update --no-pull` after replacing its files with a newer archive.

## Unsigned builds

The desktop builds and Android APK are unsigned.

- **macOS:** If Gatekeeper blocks the app, right-click it, choose **Open**, and confirm. You can also run `xattr -dr com.apple.quarantine /Applications/Hobgoblin.app` after installation.
- **Windows:** SmartScreen may warn about the installer. Continue only if you trust this GitHub Release source. WSL with a Unix-like terminal environment is recommended.
- **Android:** The APK must be signed before installation.
