Hobgoblin v2.2.5 expands multi-repository workspace workflows and strengthens Windows support. This release adds reviewed remote-branch merges, richer Branch workspace batch actions and file views, native Windows ARM64 builds, and more reliable workspace recovery and terminal path handling.

## Highlights

- **Merge local and remote branches safely:** Select explicit local or remote sources, fetch and revalidate remote refs before merging, and update remote destinations through isolated temporary worktrees with exact-ref pushes.
- **Review and run Branch workspace actions:** Batch-discard reviewed changes, select all eligible merge members with tri-state controls, edit branch upstreams safely, and keep create, reload, and progress actions accessible from the fixed workspace titlebar.
- **Explore complete workspace file views:** Open aggregate Status, Files, Changes, History, Local, and Remote views across Branch workspace members, or detach a complete file explorer with independent tab navigation.
- **Run reliably on Windows:** Prefer trusted PowerShell shells with safe fallbacks, preserve Unicode working directories and stable terminal path identity, open remote paths through local editor CLIs, and download a native Windows ARM64 installer.

## Workflow and interface updates

- Recover missing or invalid workspace configuration through explicit repair flows and automatically import eligible repositories without false configuration warnings.
- Route workspace parent navigation to a viable root terminal, close untouched terminals without unnecessary confirmation, and restore the appropriate file-area tab when reopening.
- Default newly selected worktree dependencies to copy mode, provide select-all controls for eligible batch merges, and parse CRLF and NUL-delimited worktree output consistently.
- Keep Branch workspace creation and reload controls visible while repository lists scroll, and render complete aggregate file areas for Branch workspaces and plain workspaces.

## Reliability and compatibility

- Reconcile renderer and server terminal sessions through platform-aware path identity while preserving repository-owned path spelling.
- Harden Windows release validation with packaged ConPTY smoke coverage for x64 and ARM64 artifacts.
- Exclude unused Bouncy Castle providers from Android SSHJ packaging while retaining platform-backed supported key flows.
- Remove obsolete desktop and Android code paths to reduce maintenance surface without changing supported workflows.

## Linux Server Mode

`Hobgoblin-2.2.5-linux-source.tar.gz` contains the tracked Web/Server sources, configuration, licenses, and deployment scripts required for Linux Server Mode.

Install Node.js 24+ and Bun 1.3.11, then run:

```sh
tar -xzf Hobgoblin-2.2.5-linux-source.tar.gz
cd Hobgoblin-2.2.5
./scripts/serve-systemd.sh
```

Because the deployment archive does not contain Git metadata, use `./scripts/serve-systemd.sh update --no-pull` after replacing its files with a newer archive.

## Unsigned builds

The desktop builds and Android APK are unsigned.

- **macOS:** If Gatekeeper blocks the app, right-click it, choose **Open**, and confirm. You can also run `xattr -dr com.apple.quarantine /Applications/Hobgoblin.app` after installation.
- **Windows:** SmartScreen may warn about the installer. Continue only if you trust this GitHub Release source.
- **Android:** The APK must be signed before installation.
