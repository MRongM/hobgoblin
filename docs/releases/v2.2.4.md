Hobgoblin v2.2.4 makes parallel worktree setup and mobile terminal control more predictable. This release adds lazy multi-level dependency selection for new worktrees, stabilizes Mobile Web terminal controls across authority changes, introduces read-only tmux history paging, and improves Branch workspace navigation and notification reliability.

## Highlights

- **Browse and select worktree dependencies:** Choose files or directories at any depth from any existing source worktree, then copy or symbolically link each selection into a newly created worktree. The tree loads directories on demand and supports the same best-effort behavior for local and SSH repositories.
- **Stable Mobile Web terminal controls:** Previous terminal, next terminal, and Return to bottom remain available while terminals or attachment authority change. Controller extra keys follow system keyboard visibility, while viewers and unowned attachments retain a direct takeover path.
- **Read-only tmux history paging:** Viewers and unowned attachments can move one page up or down through tmux history without taking terminal input control. Requests are validated against the exact project server and session target, and reaching the live bottom exits copy mode.
- **Faster Branch workspace navigation:** Double-click a Branch workspace member to open or collapse its file area without changing member-summary expansion. Compact terminal navigation also keeps project, Branch workspace, and terminal context consistently reachable.

## Workflow and interface updates

- Select nested dependencies such as environment or package directories even when they live below tracked parent directories.
- Skip tracked, unsafe, missing, symbolic-link, or already-occupied dependency targets without rolling back a successfully created worktree.
- Keep Mobile Web internal-terminal shortcuts visible while removing the lower-value inline editor shortcut from compact list rows.
- Use a 13px default for application and file-tree text while preserving the 14px terminal default.

## Reliability and security

- Open OSC 8 hyperlinks only through the shared Ctrl/Meta-click path and continue to reject non-HTTP protocols.
- Treat a native notification click as successful delivery and stop waiting when no presentation event arrives within the delivery timeout.
- Preserve terminal input authority while read-only tmux navigation changes the shared pane position.

## Linux Server Mode

`Hobgoblin-2.2.4-linux-source.tar.gz` contains the tracked Web/Server sources, configuration, licenses, and deployment scripts required for Linux Server Mode.

Install Node.js 24+ and Bun 1.3.11, then run:

```sh
tar -xzf Hobgoblin-2.2.4-linux-source.tar.gz
cd Hobgoblin-2.2.4
./scripts/serve-systemd.sh
```

Because the deployment archive does not contain Git metadata, use `./scripts/serve-systemd.sh update --no-pull` after replacing its files with a newer archive.

## Unsigned builds

The desktop builds and Android APK are unsigned.

- **macOS:** If Gatekeeper blocks the app, right-click it, choose **Open**, and confirm. You can also run `xattr -dr com.apple.quarantine /Applications/Hobgoblin.app` after installation.
- **Windows:** SmartScreen may warn about the installer. Continue only if you trust this GitHub Release source.
- **Android:** The APK must be signed before installation.
