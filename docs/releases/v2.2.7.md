Hobgoblin v2.2.7 makes multi-repository Git workflows faster to coordinate and easier to recover. This release adds searchable branch selection, concurrent Branch workspace Git actions, safer merge-in and merge-out flows, recent-repository navigation, and immediate in-app feedback. Its Windows downloads were built from the independent Windows package and can therefore differ from the primary macOS application; v2.2.8 corrects that release boundary.

## Highlights

- **Coordinate Branch workspace Git actions concurrently:** Run commit, pull, merge-in, and merge-out pipelines across up to four repository members at once while preserving ordered results, cancellation, cleanup, and per-member progress.
- **Find and merge the right branch faster:** Search merge source and destination lists, switch worktrees to remote branches through new tracking branches, see upstream state where Git decisions are made, and use pull-merge-push as the primary merge-in action.
- **Merge committed work without blocking on unrelated edits:** Merge out committed source history from an otherwise dirty source worktree while still blocking unresolved conflicts and revalidating source history before execution.
- **Recover interrupted workspace changes:** Replan interrupted Branch workspace creation and extension without discarding completed members, and keep failed operations visible with actionable progress.
- **Stay oriented across repositories:** Open recent repositories from tab and sidebar menus, jump directly to contextual file areas, and receive immediate success, warning, and error feedback through the shared in-app notification surface.

## Git workflow improvements

- Select repositories individually during batch commit, retry AI message generation, and remove an existing upstream when required.
- Keep repository-member pipelines independent: bounded concurrency improves throughput while failures remain isolated, aggregated, and reported in manifest order.
- Promote synchronized pull-merge-push actions without removing the plain local merge option.
- Preserve exact merge safety with fresh source-HEAD and conflict-state checks instead of treating ordinary staged, unstaged, or untracked content as a merge-out blocker.
- Improve merge-conflict handoff guidance without exposing repository-specific details in generic UI copy.

## Workspace and interface updates

- Show richer Branch workspace batch progress and recovery state across the primary desktop application and web.
- Add reusable branch-prefix selection and concise push labels while keeping upstream details visible in the relevant dialogs.
- Retain detached file areas as captured panels with reveal and back navigation.
- Add platform-specific Telegram bot artwork designed for circular avatar crops.

## Linux Server Mode

`Hobgoblin-2.2.7-linux-source.tar.gz` contains the tracked Web/Server sources, configuration, licenses, and deployment scripts required for Linux Server Mode.

Install Node.js 24+ and Bun 1.3.11, then run:

```sh
tar -xzf Hobgoblin-2.2.7-linux-source.tar.gz
cd Hobgoblin-2.2.7
./scripts/serve-systemd.sh
```

Because the deployment archive does not contain Git metadata, use `./scripts/serve-systemd.sh update --no-pull` after replacing its files with a newer archive.

## Unsigned builds

The desktop builds and Android APK are unsigned.

- **macOS:** If Gatekeeper blocks the app, right-click it, choose **Open**, and confirm. You can also run `xattr -dr com.apple.quarantine /Applications/Hobgoblin.app` after installation.
- **Windows:** SmartScreen may warn about the installer. Continue only if you trust this GitHub Release source. WSL with a Unix-like terminal environment is recommended.
- **Android:** The APK must be signed before installation.
