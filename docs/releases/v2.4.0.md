Hobgoblin v2.4.0 brings folder-based subworkspaces, file previews, and terminal stashing to the desktop and Web workspace.

## Highlights

- **Organize work by folder.** Create an empty subworkspace or bring existing repositories and linked worktrees together in one folder. Refresh the folder to discover its current members and branches. Unregistering a folder keeps its contents on disk. Deleting the folder is a separate action that asks for confirmation.
- **Follow file references from a terminal.** Click a path inside the current worktree to select it in Files. Choose **Open preview** from the terminal link menu to read supported text files at the referenced line or inspect an image. Double-click a link to open it in your editor.
- **Put a running terminal aside.** Stash a terminal tab while its process keeps running, then restore it from the project’s terminal menu.
- **See which repositories need attention.** Repository rows show how many commits the current branch is ahead of or behind its upstream. The workspace overview totals each direction separately, and you can refresh a single folder and its members.
- **Work with directory paths.** Drag a repository, workspace, or worktree row into a writable terminal to insert its directory path. The Open menu also offers a shortcut to the parent directory in the desktop file manager.

## Linux Server Mode

Install Node.js 24 or later and Bun 1.3.11, then unpack the source archive and start the service.

```sh
tar -xzf Hobgoblin-2.4.0-linux-source.tar.gz
cd Hobgoblin-2.4.0
./scripts/serve-systemd.sh
```

For an existing installation from a source archive, replace the files and run `./scripts/serve-systemd.sh update --no-pull`.
