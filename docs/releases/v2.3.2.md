Hobgoblin v2.3.2 improves Branch workspace discovery, synchronization, and desktop workspace navigation. This release makes manually materialized workspaces discoverable, keeps repository identities stable across refreshes, retries transient Git failures, and removes unavailable repositories from workspace views when rescanning.

## Highlights

- **Discover Branch workspaces reliably:** Detect manually created `hob-*` and `hobgoblin-*` directories from registered worktrees with deterministic ordering, while preserving saved workspace identities and in-progress operations.
- **Keep repository projections accurate:** Resolve discovered members to their physical worktrees and primary repository identities so branch and path changes remain visible without rewriting persisted configuration.
- **Retry transient Git failures:** Retry recoverable workspace Git actions with bounded backoff and clear operation state, while preserving cancellation and stale-result safeguards.
- **Serialize workspace actions safely:** Wait for cancelled executions to settle, prevent stale updates from winning, and replan when an execution result no longer matches the current workspace state.
- **Prune unavailable repositories on rescan:** Remove repositories that are no longer available from the active workspace projection while retaining valid workspace and terminal state.
- **Use a desktop three-column workspace:** Wide Electron and browser workspaces now place navigation, terminal/detail, and the complete file area from left to right, with independent file-area sizing and collapse behavior.
- **Document the updated workspace model:** Add implementation plans and design guidance for the three-column layout, discovery, retry, and unavailable-repository handling.

## Linux Server Mode

`Hobgoblin-2.3.2-linux-source.tar.gz` contains the tracked Web/Server sources, configuration, licenses, and deployment scripts required for Linux Server Mode.

Install Node.js 24+ and Bun 1.3.11, then run:

```sh
tar -xzf Hobgoblin-2.3.2-linux-source.tar.gz
cd Hobgoblin-2.3.2
./scripts/serve-systemd.sh
```

Because the deployment archive does not contain Git metadata, use `./scripts/serve-systemd.sh update --no-pull` after replacing its files with a newer archive.

## Unsigned builds

The desktop builds and Android APK are unsigned.

- **macOS:** If Gatekeeper blocks the app, right-click it, choose **Open**, and confirm. You can also run `xattr -dr com.apple.quarantine /Applications/Hobgoblin.app` after installation.
- **Windows:** SmartScreen may warn about the installer. Continue only if you trust this GitHub Release source. WSL with a Unix-like terminal environment is recommended.
- **Android:** The APK must be signed before installation.
