Hobgoblin v2.2.3 makes terminal-heavy development faster to navigate across desktop, browser, and Android. This release adds global internal-terminal switching, richer mobile terminal interaction, broader tmux recovery and import workflows, and a macOS `hob` command for opening projects directly from the shell.

## Highlights

- **Global terminal navigation:** Move through every open internal terminal across projects and worktrees with `Cmd+Option+Up/Down` on macOS or `Ctrl+Alt+Up/Down` on Windows and Linux. Desktop, mobile, controller, and read-only terminal surfaces also expose consistent previous/next controls.
- **Mobile terminal interaction:** Use a compact command deck, direct scroll gestures with inertia, an edge scrubber for long history, local long-press text selection and copy, and canonical viewer geometry that keeps shared terminal output aligned.
- **Expanded tmux workflows:** Inspect and manage default-host tmux sessions from desktop, reconnect deterministic project sessions, and import a discovered Android tmux directory as either a Git repository or a plain project.
- **Open projects with `hob`:** Run `hob .` or `hob <directory>` on macOS to open or import a local directory in Hobgoblin. Packaged builds include the launcher, while local app installation creates a safe user-scoped link without overwriting an existing command.

## Workflow and interface updates

- Add localized built-in terminal button presets and preserve terminal focus after command-dock actions.
- Improve return-to-bottom behavior for ordinary and tmux-backed terminals without injecting terminal input.
- Surface Android project recency, retained-terminal opened time, and clearer running, disconnected, failed, exited, and starting states.
- Consolidate Files and Security settings, simplify compact Branch workspace controls, and remove obsolete View, Application, Navigation, and operating-system global shortcut controls.
- Keep the Status tab focused by retaining one whole-status copy action and removing repetitive per-field copy buttons.

## Linux Server Mode

`Hobgoblin-2.2.3-linux-source.tar.gz` contains the tracked Web/Server sources, configuration, licenses, and deployment scripts required for Linux Server Mode.

Install Node.js 24+ and Bun 1.3.11, then run:

```sh
tar -xzf Hobgoblin-2.2.3-linux-source.tar.gz
cd Hobgoblin-2.2.3
./scripts/serve-systemd.sh
```

Because the deployment archive does not contain Git metadata, use `./scripts/serve-systemd.sh update --no-pull` after replacing its files with a newer archive.

## Unsigned builds

The desktop builds and Android APK are unsigned.

- **macOS:** If Gatekeeper blocks the app, right-click it, choose **Open**, and confirm. You can also run `xattr -dr com.apple.quarantine /Applications/Hobgoblin.app` after installation.
- **Windows:** SmartScreen may warn about the installer. Continue only if you trust this GitHub Release source.
- **Android:** The APK must be signed before installation.
