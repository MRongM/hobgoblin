Hobgoblin v2.2.6 makes Windows independently buildable and testable while recommending WSL as the Unix-like terminal environment. This release adds WSL-first internal and external terminal launching with native fallbacks, independent Windows x64 and ARM64 packaging, stronger ConPTY validation, global terminal navigation, and richer Branch workspace controls.

## Highlights

- **Use WSL-first terminals on Windows:** Detect a usable default WSL distribution with a bounded system probe, prefer it for internal terminals and external Windows Terminal launches, and retain PowerShell and native Windows shell fallbacks.
- **Ship an independent Windows package:** Keep the primary application's Windows path under `src/` while building the source-isolated package under `windows/` as the independent x64 and ARM64 release implementation.
- **Navigate terminals globally:** Move through open internal terminals across projects and worktrees with platform shortcuts and configurable navigation controls.
- **Coordinate Branch workspaces faster:** Show member change counts, refine member interactions, expose settings and batch actions, and update selected branch upstreams together.

## Windows terminal behavior

- Resolve `%SystemRoot%\System32\wsl.exe` case-insensitively and require a successful, non-empty distribution probe before selecting WSL.
- Open valid Windows working directories in the default WSL distribution through Windows Terminal without interpolating paths into shell text.
- Preserve native Windows Terminal behavior when WSL is unavailable and fall back to PowerShell when Windows Terminal cannot launch.
- Keep touch-capable Windows desktop renderers out of the Mobile Web command deck while preserving explicit mobile user-agent and non-Windows touch detection.

## Reliability and packaging

- Restore architecture-matched ConPTY companion assets after native dependency rebuilds for independent Windows x64 and ARM64 installers.
- Validate packaged Windows terminal startup and ConPTY behavior in CI, and upload a primary-application Windows x64 test artifact alongside independent-package artifacts.
- Keep root and independent Windows terminal behavior equivalent without introducing runtime coupling between their source trees.
- Preserve existing invalid-path, missing-terminal, and native-shell fallback behavior.

## Linux Server Mode

`Hobgoblin-2.2.6-linux-source.tar.gz` contains the tracked Web/Server sources, configuration, licenses, and deployment scripts required for Linux Server Mode.

Install Node.js 24+ and Bun 1.3.11, then run:

```sh
tar -xzf Hobgoblin-2.2.6-linux-source.tar.gz
cd Hobgoblin-2.2.6
./scripts/serve-systemd.sh
```

Because the deployment archive does not contain Git metadata, use `./scripts/serve-systemd.sh update --no-pull` after replacing its files with a newer archive.

## Unsigned builds

The desktop builds and Android APK are unsigned.

- **macOS:** If Gatekeeper blocks the app, right-click it, choose **Open**, and confirm. You can also run `xattr -dr com.apple.quarantine /Applications/Hobgoblin.app` after installation.
- **Windows:** SmartScreen may warn about the installer. Continue only if you trust this GitHub Release source. WSL with a Unix-like terminal environment is recommended.
- **Android:** The APK must be signed before installation.
