Hobgoblin v2.2.2 makes multi-repository worktree workflows more deliberate, resilient, and easier to recover. This release adds explicit worktree creation controls, stronger batch Git automation, faster terminal opening, and clearer repository actions across desktop and browser workflows.

## Highlights

- **Controlled worktree creation:** Choose a local or remote base, optionally synchronize it before creation, and explicitly opt in before copying or linking dependency candidates.
- **Resilient branch workspace automation:** Continue batch Git operations after individual repository failures, aggregate diagnostics, retry only failed repositories, and hand unresolved errors to an AI terminal with the relevant context.
- **AI-assisted commit and push:** Opt in to generate a commit message, commit the selected changes, and then use the existing protected push flow for individual branches or branch workspace batches.
- **Clearer workspace navigation:** Open multi-repository workspaces at Overview, detect repositories from plain project roots, access repository remote links from project menus, and create or synchronize ordinary worktrees from their own menus.

## Reliability and polish

- Coalesce identical concurrent local and remote terminal-open requests so repeated actions reuse the same in-flight launch.
- Match missing tmux sockets precisely on macOS without hiding unrelated tmux failures.
- Preserve explicit busy and disabled states across worktree actions, and align dropdown and context-menu scrollbars with the active theme.

## Linux Server Mode

`Hobgoblin-2.2.2-linux-source.tar.gz` contains the tracked Web/Server sources, configuration, licenses, and deployment scripts required for Linux Server Mode.

Install Node.js 24+ and Bun 1.3.11, then run:

```sh
tar -xzf Hobgoblin-2.2.2-linux-source.tar.gz
cd Hobgoblin-2.2.2
./scripts/serve-systemd.sh
```

Because the deployment archive does not contain Git metadata, use `./scripts/serve-systemd.sh update --no-pull` after replacing its files with a newer archive.

## Unsigned builds

The desktop builds and Android APK are unsigned.

- **macOS:** If Gatekeeper blocks the app, right-click it, choose **Open**, and confirm. You can also run `xattr -dr com.apple.quarantine /Applications/Hobgoblin.app` after installation.
- **Windows:** SmartScreen may warn about the installer. Continue only if you trust this GitHub Release source.
- **Android:** The APK must be signed before installation.
