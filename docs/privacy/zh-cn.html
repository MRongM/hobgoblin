隐私政策

Hobgoblin 将您的 Android 设备直接连接到您选择的 SSH 主机。MRongM 不运营 Hobgoblin 账户或应用后端。

English简体中文日本語한국어

生效日期：2026-07-28 · 开发者：MRongM

1. 适用范围

本政策适用于 MRongM 发布的 Hobgoblin Android 应用。本政策不控制您选择配合 Hobgoblin 使用的 SSH 服务器、Git 托管服务、网络提供商、Android 系统服务或第三方应用。

2. MRongM 不收集的数据

Hobgoblin 没有由 MRongM 运营的应用后端，也不包含广告、分析或崩溃报告 SDK。MRongM 不会从应用接收账户数据、遥测数据、广告标识符、终端内容、仓库内容、SSH 凭据或设备信息。

3. 存储在设备上的信息

为了提供您主动使用的功能，Hobgoblin 会在应用私有存储中保存主机别名、主机地址、用户名、端口、远程路径、可信主机密钥指纹、端口转发规则、显示偏好、手动顺序、保留终端元数据，以及有长度上限的近期终端输出快照。导入或生成的 SSH 私钥使用 AES-GCM 加密，密钥由 Android Keystore 保管。当您明确导出私钥时，原始私钥字节会发送到您选择的文档提供方，导出的文档不再受 Hobgoblin 应用内加密私有存储保护。用于安装公钥的临时服务器密码只在该次操作期间于内存中处理，之后会被清除，Hobgoblin 不会保存该密码。

4. 直接 SSH 连接

连接时，命令、终端输入与输出、仓库元数据、远程路径及相关响应会在您的设备与您选择的 SSH 服务器之间直接传输，并由 SSH 进行传输加密。MRongM 不是中间方，无法读取或获取这些内容。服务器所有者和网络提供商可能依据其自身政策处理数据。

5. Termux 与剪贴板

Termux 集成是可选功能，只有在您明确操作后才会运行。具备直接 Termux 命令权限时，Hobgoblin 可能将 SSH 命令和所选私钥材料发送给单独安装的 Termux 应用，以启动您要求的会话。如果选择“复制命令”，SSH 命令会被放入 Android 剪贴板。Termux 和其他剪贴板读取方受其自身行为与政策约束。

6. 通知

交互式 SSH 终端保持活动时，Hobgoblin 会使用持续显示的 Android 通知。通知可能显示终端标签和连接状态；锁屏可见性由您的设备通知设置控制。

7. 信息共享

MRongM 不出售或共享从应用收到的数据，因为 MRongM 不会收到这些数据。仅在执行您发起的操作时，数据才会按上述方式到达您选择的 SSH 服务器、Termux 或剪贴板。若收到有效法律要求，MRongM 可能依法披露其持有的信息，但无法披露其并未持有的应用数据。

8. 保留与删除

本地记录会保留到您通过应用中已有的删除控件移除、在 Android 设置中清除 Hobgoblin 存储，或卸载应用为止。清除存储或卸载会删除 Hobgoblin 剩余的本地应用数据。结束或删除 Hobgoblin 记录不会删除 SSH 服务器上的文件、Git 仓库、Shell 历史、authorized_keys 或 tmux 会话；只有当应用明确预览单独的远程操作并得到您确认时才会执行该操作。MRongM 不保存服务器端 Hobgoblin 账户数据，因此没有服务器端用户记录可供删除。

9. 安全性

Hobgoblin 使用 Android 应用私有存储、Android Keystore 支持的私钥加密、SSH 传输加密和明确的主机密钥信任。任何系统都无法保证绝对安全。您需要负责保护自己的设备、SSH 服务器、凭据、Termux 安装和网络。

10. 儿童隐私

Hobgoblin 是面向 18 岁及以上成年人的专业开发工具，不面向儿童。MRongM 不会有意通过本应用收集儿童的个人信息。

11. 跨境使用

您的设备与所选 SSH 服务器可能位于不同国家或地区。您有责任确保自己对 SSH、加密技术、仓库和远程系统的使用符合适用于您的法律及组织规定。

12. 政策变更

当 Hobgoblin 的行为或法律义务发生变化时，本政策可能更新。上方生效日期会相应修改；必要时，重大变化也会在本页面、应用或商店资料中体现。

13. 联系方式
