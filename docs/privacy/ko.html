개인정보 처리방침

Hobgoblin은 Android 기기를 사용자가 선택한 SSH 호스트에 직접 연결합니다. MRongM은 Hobgoblin 계정이나 앱 백엔드를 운영하지 않습니다.

시행일: 2026-07-28 · 개발자: MRongM

1. 적용 범위

본 방침은 MRongM이 제공하는 Hobgoblin Android 앱에 적용됩니다. 사용자가 Hobgoblin과 함께 사용하기로 선택한 SSH 서버, Git 호스트, 네트워크 제공자, Android 시스템 서비스 또는 타사 앱에는 적용되지 않습니다.

2. MRongM이 수집하지 않는 데이터

Hobgoblin에는 MRongM이 운영하는 앱 백엔드가 없으며 광고, 분석 또는 비정상 종료 보고 SDK가 포함되어 있지 않습니다. MRongM은 앱 계정 데이터, 원격 측정 정보, 광고 식별자, 터미널 내용, 저장소 내용, SSH 자격 증명 또는 기기 정보를 앱에서 수신하지 않습니다.

3. 기기에 저장되는 정보

사용자가 요청한 기능을 제공하기 위해 Hobgoblin은 호스트 별칭, 주소, 사용자 이름, 포트, 원격 경로, 신뢰한 호스트 키 지문, 포트 포워딩 규칙, 표시 설정, 수동 순서, 보존된 터미널 메타데이터 및 길이가 제한된 최근 터미널 출력 스냅샷을 비공개 앱 저장소에 저장합니다. 가져오거나 생성한 SSH 개인 키는 Android Keystore에 보관된 키를 사용하여 AES-GCM으로 암호화됩니다. 사용자가 개인 키를 명시적으로 내보내면 원본 개인 키 바이트가 선택한 문서 제공자에 전달되며, 내보낸 문서는 Hobgoblin의 암호화된 비공개 앱 저장소 보호를 받지 않습니다. 공개 키 설치에 사용하는 임시 서버 암호는 해당 시도 중에만 메모리에서 처리되고 이후 지워지며 Hobgoblin에 저장되지 않습니다.

4. 직접 SSH 연결

연결할 때 명령, 터미널 입력과 출력, 저장소 메타데이터, 원격 경로 및 관련 응답은 기기와 사용자가 선택한 SSH 서버 사이에서 직접 전송되며 SSH로 전송 중 암호화됩니다. MRongM은 중개자가 아니며 그 내용을 읽거나 가져올 수 없습니다. 서버 소유자와 네트워크 제공자는 각자의 방침에 따라 데이터를 처리할 수 있습니다.

5. Termux 및 클립보드

Termux 연동은 선택 사항이며 사용자가 명시적으로 실행한 경우에만 동작합니다. Termux 직접 명령 권한을 사용할 수 있으면 Hobgoblin은 요청한 세션을 시작하기 위해 SSH 명령과 선택한 개인 키 자료를 별도로 설치된 Termux 앱에 보낼 수 있습니다. 명령 복사를 선택하면 SSH 명령이 Android 클립보드에 저장됩니다. Termux와 다른 클립보드 판독기에는 각각의 동작과 방침이 적용됩니다.

6. 알림

대화형 SSH 터미널이 활성 상태인 동안 Hobgoblin은 진행 중인 Android 알림을 사용합니다. 알림에는 터미널 레이블과 연결 상태가 표시될 수 있습니다. 잠금 화면 노출 여부는 기기의 알림 설정으로 관리합니다.

7. 공유

MRongM은 앱으로부터 데이터를 받지 않으므로 수신 데이터를 판매하거나 공유하지 않습니다. 사용자가 시작한 작업을 수행할 때에만 위 설명에 따라 데이터가 선택한 SSH 서버, Termux 또는 클립보드에 전달됩니다. 유효한 법적 요청이 있는 경우 MRongM은 보유 정보를 공개할 수 있으나, 보유하지 않은 앱 데이터는 공개할 수 없습니다.

8. 보관 및 삭제

로컬 기록은 앱에서 제공되는 삭제 기능으로 제거하거나, Android 설정에서 Hobgoblin 저장공간을 지우거나, 앱을 제거할 때까지 보관됩니다. 저장공간 지우기 또는 앱 제거는 남아 있는 Hobgoblin 로컬 앱 데이터를 삭제합니다. Hobgoblin 기록을 닫거나 삭제해도 SSH 서버의 파일, Git 저장소, Shell 기록, authorized_keys 또는 tmux 세션은 삭제되지 않습니다. 앱이 별도의 원격 작업을 명확히 미리 보여 주고 사용자가 승인한 경우에만 해당 작업이 실행됩니다. MRongM은 서버 측 Hobgoblin 계정 데이터를 보관하지 않으므로 삭제할 서버 측 사용자 기록이 없습니다.

9. 보안

Hobgoblin은 Android 비공개 앱 저장소, Android Keystore 기반 개인 키 암호화, SSH 전송 암호화 및 명시적인 호스트 키 신뢰를 사용합니다. 어떤 시스템도 절대적인 보안을 보장할 수 없습니다. 기기, SSH 서버, 자격 증명, Termux 설치 및 네트워크 보안은 사용자의 책임입니다.

10. 아동

Hobgoblin은 만 18세 이상 성인을 위한 전문 개발 도구이며 아동을 대상으로 하지 않습니다. MRongM은 본 앱을 통해 아동의 개인정보를 고의로 수집하지 않습니다.

11. 국제적 사용

기기와 선택한 SSH 서버가 서로 다른 국가에 있을 수 있습니다. SSH, 암호화 기술, 저장소 및 원격 시스템 사용이 사용자에게 적용되는 법률과 조직 규칙을 준수하는지 확인할 책임은 사용자에게 있습니다.

12. 변경

Hobgoblin의 동작 또는 법적 의무가 변경되면 본 방침을 업데이트할 수 있습니다. 위 시행일을 수정하고 필요한 경우 중요한 변경 사항을 이 페이지, 앱 또는 스토어 등록정보에 반영합니다.
