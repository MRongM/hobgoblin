# 文件夹式分支管理 Implementation Plan

当前执行方式以用户最新要求为准：只登记文件夹位置，成员和分支从磁盘读取；不自动提交代码，先实现功能，由用户手动验证。

## 已实现

- [x] 文件夹名称展示、自定义存放目录、已有文件夹登记及空文件夹创建。
- [x] v3 位置登记，只保存稳定 ID 和路径；兼容旧登记的 ID、路径及顺序。
- [x] 刷新时发现实际仓库、工作树和当前分支，支持用户手动增删、切换及目录别名。
- [x] 完整仓库和工作树混用；应用内创建操作为可选辅助功能。
- [x] 从列表移除仅注销登记，保留文件、Git 数据和终端。
- [x] 文件、终端、成员分支切换与独立文件窗口按实际目录定位。
- [x] 可选远程工作副本克隆的传输、恢复、取消、界面和接口。
- [x] 取消文件树读取时正常处理过期请求，配置恢复不删除文件夹内容。
- [x] en、zh、ja、ko 文案与菜单接入。
- [x] 最终类型检查、架构检查和差异检查。

## 验证边界

最终实现通过 `bun run typecheck` 和 `bun run check:architecture`。按用户要求，最新位置登记模型未继续运行完整测试、浏览器验证或审查循环；早期基于严格成员清单的测试预期未在本轮全面重写。远程克隆的特殊 Git 状态、链接和传输大小限制详见当前实现与手动验证反馈。

后续改动保留在工作区，不暂存、不自动提交、不推送，不改写此前本地历史。
