# Android i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Localize all Android-owned user-facing copy in English, Simplified Chinese, Japanese, and Korean using Android's native resource system.

**Architecture:** Android resource qualifiers own static and formatted copy. Compose resolves resources at screen boundaries, services use `Context.getString`, and domain/transport values remain raw and locale-independent. Android generates its per-app locale configuration from the shipped resources.

**Tech Stack:** Kotlin, Jetpack Compose, Android resources, AGP 9.0, JUnit 4

## Global Constraints

- English is the complete unqualified fallback locale.
- Supported translations are Simplified Chinese, Japanese, and Korean.
- Do not translate terminal output, commands, paths, repository/host identifiers, or raw Git/SSH/Termux diagnostics.
- Do not add dependencies or an in-app language preference.
- Do not execute Git commits; repository instructions require explicit user confirmation.
