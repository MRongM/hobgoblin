# Hobgoblin v2.2.1 Workspace and Linux Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish Hobgoblin v2.2.1 with localized workspace/Android/tmux documentation, a tested Linux Server Mode source archive, updated Pages, and verified GitHub Release assets.

**Architecture:** A focused Node.js strip-only script builds a deployment-only archive from an allowlist of tracked Web/Server sources. GitHub Actions treats that archive as a fourth parallel platform artifact and the existing publish job validates and uploads it with macOS, Windows, and Android assets. Public documentation and release notes share the canonical multi-repository workspace and Branch workspace model.

**Tech Stack:** Node.js 24 strip-only TypeScript, Bun 1.3.11, Vitest 4, GitHub Actions, Bash/systemd, static HTML i18n, Android Gradle/Kotlin.

## Global Constraints

- Use `Branch workspace` as the canonical public term; do not introduce generic “subworkspace” terminology.
- Every repository member remains an independent Git operation boundary.
- Cross-repository operations are sequential, stop on first failure, retain completed results, and do not auto-rollback.
- The Linux archive requires Node.js 24+ and Bun at deployment time.
- Do not add dependencies or change `bun.lock`.
- Do not use TypeScript enums, runtime namespaces, parameter properties, or import aliases.
- Use repo-alias imports with explicit `.ts`/`.tsx` extensions in application source.
- Keep all examples privacy-safe.
- Defer Git commits, merges, pushes, tag creation, Release mutation, and workflow dispatch until the final consolidated safety confirmation.

```ts
test('builds a deployment-only Linux source archive', () => {
  const packageJson = JSON.parse(readText('package.json')) as { version: string }
  const outputDir = mkdtempSync(path.join(tmpdir(), 'hobgoblin-linux-source-test-'))
  const extractDir = path.join(outputDir, 'extract')
  const rootName = `Hobgoblin-${packageJson.version}`
  const archivePath = path.join(outputDir, `${rootName}-linux-source.tar.gz`)

  try {
    execFileSync(
      process.execPath,
      [path.join(repoRoot, 'scripts/build-linux-source-archive.ts'), '--output-dir', outputDir],
      { cwd: repoRoot, stdio: 'pipe' },
    )
    mkdirSync(extractDir)
    execFileSync('tar', ['-xzf', archivePath, '-C', extractDir])

    expect(existsSync(path.join(extractDir, rootName, 'scripts/serve-systemd.sh'))).toBe(true)
    expect(existsSync(path.join(extractDir, rootName, 'src/server/bootstrap.ts'))).toBe(true)
    expect(existsSync(path.join(extractDir, rootName, 'src/system/git/helper.ts'))).toBe(true)
    expect(existsSync(path.join(extractDir, rootName, 'src/web/index.html'))).toBe(true)
    expect(statSync(path.join(extractDir, rootName, 'scripts/serve-systemd.sh')).mode & 0o111).not.toBe(0)
    expect(existsSync(path.join(extractDir, rootName, 'src/web/App.test.tsx'))).toBe(false)
    expect(existsSync(path.join(extractDir, rootName, 'src/main/main.ts'))).toBe(false)
    expect(existsSync(path.join(extractDir, rootName, 'android/app/build.gradle.kts'))).toBe(false)
    expect(existsSync(path.join(extractDir, rootName, 'docs'))).toBe(false)
  } finally {
    rmSync(outputDir, { recursive: true, force: true })
  }
})
```
