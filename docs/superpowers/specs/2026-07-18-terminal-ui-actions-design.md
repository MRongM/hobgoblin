# 终端 UI 操作调整 — 设计

日期：2026-07-18
状态：自主确认并执行

## 目标

统一工作树与终端的高频入口：工作树行直接新建内部终端，将浏览器与局域网二维码入口下沉到左下角状态栏，并为每个终端 tab 提供带二次确认的批量关闭右键菜单。

## 需求

1. 工作树行内“编辑”按钮后的外部终端动作改为内部终端图标；点击后选中该工作树、展开终端详情并新建一个内部终端。
2. 终端 topbar 右侧的“在浏览器中打开”和“局域网终端二维码”图标移到桌面端左下角状态栏；链接继续指向当前选中工作树与当前选中终端。
3. 右击任一终端 tab 显示当前工作树范围内的三个动作：关闭当前终端、关闭其他终端、关闭全部终端。
4. 三个右键关闭动作都必须先显示破坏性确认对话框；取消时不得关闭任何终端。

## 方案取舍

- **A（采用）复用终端会话上下文，并抽出状态栏终端访问组件。** 工作树动作调用现有 `createTerminal`；状态栏组件集中构造 deep link 与二维码；tab 菜单把关闭意图映射为现有单终端 `onClose`。改动局限于渲染层，职责清晰且不复制服务端清理逻辑。
- B 将所有动作继续堆在 `BranchDetailToolbar`，再通过跨组件回调驱动状态栏。会造成详情 topbar 与侧栏状态栏相互耦合，弃用。
- C 新增服务端批量关闭 API。现有关闭回调已经拥有完整清理语义，批量 API 会增加不必要的边界与错误协议，违反 YAGNI，弃用。

## 组件设计

### 工作树内部终端动作

`useBranchActionItems` 中保留现有 `terminal` 动作 ID，以兼容已保存的快捷动作标识，但将其语义改为“新终端”：

- 图标使用 Lucide 内部终端图标，不再使用由外部终端应用设置决定的应用图标。
- 不再依赖本机外部终端应用可用性；只要分支有工作树且当前操作未阻塞即可执行。
- 执行时打开当前仓库的 `terminal` 详情、展开详情区，并调用 `createTerminal(terminalBase)`。
- 外部终端底层能力与已有键盘命令保持不变；本次只替换工作树行/动作菜单中的该入口。

### 状态栏终端访问入口

新增聚焦组件 `TerminalStatusActions`，由 `StatusBar` 在有仓库时渲染。组件负责：

- 从仓库 store 解析当前选中分支及其工作树。
- 从终端会话快照解析当前选中终端。
- 使用现有 LAN info query、`buildTerminalDeepLinkUrl`、`openExternalUrl` 与二维码生成工具。
- 在状态栏左侧以 `icon-sm` 按钮渲染浏览器和二维码入口。
- 无工作树时不渲染；LAN info 未就绪时禁用浏览器入口，二维码入口仍可打开现有空状态说明。

`BranchDetailToolbar` 删除对应按钮、链接计算、二维码状态与对话框，终端 tab 和其他 topbar 行为不变。

### 终端 tab 右键菜单

每个 `ToolbarClosableTab` 可选接收一个上下文菜单内容，由通用组件在原生 tab 容器上建立 Radix `ContextMenuTrigger`，不改变现有 DOM 尺寸、拖拽 ref 或键盘 tab 语义。

`TerminalTabs` 维护一个待确认关闭意图：

- `current`：目标为被右击的 tab。
- `others`：目标为当前 `sessions` 中除被右击 tab 外的会话。
- `all`：目标为当前 `sessions` 全部会话。

确认时重新基于最新 `sessions` 计算目标，避免对话框打开期间关闭已经消失的旧 key。`others` 在只有一个终端时禁用。确认后逐个调用现有 `onClose(key)`；关闭当前激活 tab 时沿用现有相邻 tab 聚焦规则。

## 文案与可访问性

- 新增 `terminal.close-current` 与 `terminal.close-others` 及“关闭其他终端”的确认文案，补齐中、英、日、韩字典。
- 所有菜单项使用破坏性视觉语义；“关闭其他终端”与“关闭全部终端”的确认正文包含实时数量。
- 状态栏按钮保留 `aria-label` 与 tooltip；tab 本身继续使用 `role="tab"`、`aria-selected` 和现有键盘导航。

## 错误处理

- 新建内部终端继续使用终端会话上下文现有异步错误处理，不新增并行错误状态。
- 关闭回调没有结果通道，本次保持现有契约；确认框在调用关闭前先结束确认状态。
- 状态栏 deep link 缺少必要数据时不执行浏览器打开。

## 测试

- `useBranchActionItems.test.tsx`：工作树终端动作不依赖外部终端应用，点击后打开终端详情并创建内部终端。
- `StatusBar.test.tsx`：入口位于状态栏；浏览器 deep link 与二维码目标使用当前工作树和当前终端。
- `BranchDetailToolbar.test.tsx`：终端 topbar 不再渲染浏览器和二维码按钮。
- `TerminalTabs.test.tsx`：右键菜单作用于被右击 tab；三类关闭都先确认；取消无副作用；“关闭其他”保留目标 tab。
- `dictionaries.test.ts`、类型检查、架构检查和完整测试保持通过。

## 非目标

- 不新增终端批量关闭服务端 API。
- 不改变跨工作树或跨仓库的终端生命周期。
- 不新增键盘快捷键。
- 不改变紧凑布局是否显示桌面左下角状态栏的既有规则。
