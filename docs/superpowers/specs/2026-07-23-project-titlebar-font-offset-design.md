# 项目标题栏字号偏移修订设计

## 目标

将项目标题栏字号从“应用字体大小减 1px”调整为“应用字体大小减 2px”，同时保留 10px 下限。

## 范围

统一公式为：

```css
max(10px, calc(var(--goblin-app-font-size) - 2px))
```

该共享变量继续覆盖项目、工作区仓库、子工作区、工作树和文件区标签栏。默认应用字体为 14px 时，标题栏字号为 12px。

正文、标题栏高度、间距、右侧 `icon-sm` 操作按钮和开发者工具快捷键均不改变。

## 验证

- 先修改字体契约测试并观察其因现有 `-1px` 公式失败。
- 再修改根级共享 CSS 变量并观察测试通过。
- 运行类型检查、全量测试、架构检查和差异检查。
