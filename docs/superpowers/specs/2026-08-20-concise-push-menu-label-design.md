# 精简推送菜单标签设计

## 目标

工作树操作菜单中的推送项只显示本地化动作名称（例如“推送”），不再在可见标签中拼接 `origin/feature-name` 等上游分支信息。

## 行为约束

- 保留推送项、图标、`⇧P` 快捷键、禁用/忙碌状态和点击行为。
- 保留上游分支信息，并继续通过菜单项 `title` 提示提供。
- 不修改 Git 命令、服务端接口、状态模型或国际化词条。
- 不为工作树菜单引入新的分支判断；沿用统一的推送动作标签，避免不同入口显示不一致。

## 实现

`useBranchActionItems` 已分别计算动作状态标签和上游提示文本。推送项的 `label` 直接使用 `branchActionLabel(...)`，`title` 继续使用 `pushUpstreamLabel`。

通过 hook 单元测试锁定两个契约：可见标签等于动作文本，提示文本仍包含当前上游。

## 范围

仅修改主版本的 hook 及其测试。独立 Windows 版本当前已经只显示动作文本，且没有本次上游提示功能的在途改动，因此无需修改。
