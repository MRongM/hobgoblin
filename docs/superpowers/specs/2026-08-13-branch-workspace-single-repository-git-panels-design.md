# 子工作区单仓库 Git 面板设计

## 目标

缩短子工作区父级文件区的滚动范围。状态、变更、历史、本地和远程视图每次只显示并操作一个成员仓库，用户通过面板内的成员仓库切换器改变目标仓库。

## 范围

- 状态、变更、历史、本地和远程视图共享当前成员仓库选择。
- 首次打开子工作区时选择清单中的第一个成员。
- 切换五个 Git 视图时保留成员仓库选择。
- 文件视图继续浏览子工作区根目录。
- 不改变侧栏选择、全局活动仓库或成员工作树上下文。

## 交互设计

状态、变更、历史、本地和远程视图在内容顶部显示局部成员仓库切换器。触发器显示当前成员仓库名称，菜单按子工作区清单顺序列出全部成员。

变更 Tab 复用普通工作树的 attention 徽标显示所有可解析成员工作树的精确改动总数。变更视图中的切换器触发器显示当前成员的非零改动数，菜单中每个非零成员显示自己的精确改动数；其他 Git 视图不显示这些改动徽标。计数取目标工作树对应 `status.entries.length`，不可用或不可解析成员按 0 处理。

切换器属于父级子工作区文件区，不是工作区导航器。选择菜单项只替换当前 Git 面板内容，不离开子工作区父级上下文，也不切换到成员工作树的普通文件区。

不可用成员仍保留在菜单中。选中不可用成员时显示现有解析失败或不可用原因，不挂载仓库 Git 面板。成员从清单移除或当前子工作区改变时，选择回退到新清单中的第一个成员。

## 组件与状态

`BranchWorkspaceFileArea` 持有共享的成员仓库名称选择。选择状态保持为组件本地、非持久状态；它不属于服务端快照或仓库 Store。

`BranchWorkspaceAggregatePanel` 继续解析一次清单成员：

- `status`、`changes`、`history`、`local` 和 `remoteBranches` 渲染切换器及一个选中成员 section；
- 历史文件定位继续为相对路径加上所选成员目录前缀；
- 选中成员不可解析时复用现有 `EmptyState` 原因。

共享纯函数从已解析成员取得单成员精确改动数并计算总数，变更 Tab 与成员切换器消费同一计数口径。

局部切换器可复用现有按钮、下拉菜单和仓库图标样式，但不复用 `WorkspaceRepositorySwitcher` 的全局导航行为。

## 数据与副作用

只挂载所选仓库的状态、变更、历史、本地或远程面板，因此只有该仓库执行对应查询和操作。切换仓库会卸载旧面板并挂载新面板；已有服务器失效通知和仓库查询缓存继续作为数据权威，不引入新缓存或同步通道。

## 错误与边界

- 空成员清单保持空内容状态，不构造虚假仓库选择。
- 只有一个成员时仍显示当前仓库身份，切换菜单不产生额外目标。
- 不可用成员可被查看但不能执行仓库操作。
- 改动总数为 0 或单成员改动数为 0 时不显示计数徽标。
- 相同仓库名称是子工作区清单中的既有成员身份；不引入新的合并仓库模型。

## 文档

更新 `CONTEXT.md` 和 `docs/ui-conventions.md`，明确五个 Git 视图都是单成员目标视图。该变化是可逆的展示策略，不创建 ADR。

## 验证

- 组件测试证明状态、变更、历史、本地和远程每次只挂载所选成员面板。
- 组件测试证明五个视图共享选择，切换子工作区后回退到第一个成员。
- 组件测试证明不可用成员显示原因。
- 组件测试证明变更 Tab 显示成员改动总数，变更视图的切换器显示非零成员改动数并隐藏零值。
- 既有测试继续证明状态、变更和历史文件定位仍返回子工作区根相对路径。
- 运行 `bun run typecheck`、`bun run test` 和 `bun run check:architecture`。

## 非目标

- 不改变普通仓库或成员工作树文件区。
- 不持久化最近选择。
- 不改变文件视图。
- 不增加批量 Git 操作或跨仓库事务。
