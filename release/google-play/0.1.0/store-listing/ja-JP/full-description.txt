Hobgoblin は、自分のリモート開発マシンへ安全にアクセスしたい開発者向けの Android ワークスペースです。

自分で管理する SSH ホストへ直接接続し、リモート Git プロジェクトと worktree を整理しながら、保持された端末へプロジェクトの文脈を保ったまま戻れます。

リモート開発を一覧で確認

• 複数の SSH ホストを保存し、信頼する前にホスト鍵フィンガープリントを確認。
• 既存の SSH 秘密鍵をインポート、または一時的なサーバーパスワードで鍵アクセスを初期化。
• 絶対パスでリモート Git リポジトリまたは通常のワークスペースを追加。
• 選択したホストの worktree、ブランチ、最近のコミットを確認。

文脈を保つ端末

• ホスト、プロジェクト、worktree 用のネイティブ SSH 端末を開始。
• tmux が利用できる場合、決定的な識別子を持つプロジェクト端末を作成または再接続。
• 端末記録を整理し、切断したセッションの再接続、明示的な終了と削除が可能。
• 対話型端末が動作している間、Android の継続中通知で状態を表示。

実用的な SSH ツール

• ローカル SSH ポート転送を保存し、端末限定または LAN バインドを選択。
• プロジェクトを開く前に接続診断を実行。
• 別途インストールした Termux アプリでワークスペースセッションを開くことも可能。
• 端末の色、文字サイズ、フィット方法、モバイル入力用追加キーを調整。

Hobgoblin は SSH サーバー、クラウドアカウント、ホスト型 Git サービス、リモートマシンを提供しません。到達可能な SSH ホスト、認証情報、リモートプロジェクトのパスは利用者が用意する必要があります。リポジトリ機能には Git が必要で、tmux と Termux の連携は任意です。

広告なし。分析 SDK なし。Hobgoblin アカウントなし。
