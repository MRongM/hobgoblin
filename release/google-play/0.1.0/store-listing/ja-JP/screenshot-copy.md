# 日本語スクリーンショット順序

端末フレームや追加の宣伝文を付けず、実際の英語 UI をアップロードします。完成した各デバイス区分で同じ順序を使います。

| 順序 | ファイル | 伝える内容 | 代替テキスト |
| ---: | --- | --- | --- |
| 1 | `01-settings.png` | SSH の安定性を調整し、アプリ内でプライバシーポリシーを開く。 | keepalive 設定とプライバシーポリシーへのリンクを表示する Hobgoblin の設定画面。 |
| 2 | `02-projects.png` | リモート Git プロジェクトを正しいホストに関連付け。 | 審査用ホスト上の安全なリモート Git プロジェクトを表示する Projects タブ。 |
| 3 | `03-worktrees.png` | ブランチ、worktree、コミットをリモートで確認。 | 審査用リポジトリの worktree とリポジトリ文脈を表示する画面。 |
| 4 | `04-terminal.png` | プロジェクトの文脈を持つ SSH 端末で作業。 | 機密情報を含まない審査用コマンドと出力を表示する SSH 端末。 |
| 5 | `05-terminals.png` | 保持した端末セッションへ必要なときに戻る。 | 再接続、終了、削除操作を備えた保持セッションの Terminals タブ。 |

`03-worktrees.png` はローカルのデモ用ユーザー名とアドレス部分だけをぼかしています。製品 UI や機能状態は作り替えていません。
