Hobgoblin은 자신의 원격 개발 머신에 안전하게 접속하려는 개발자를 위한 Android 작업공간입니다.

직접 관리하는 SSH 호스트에 연결하고 원격 Git 프로젝트와 worktree를 정리하며, 프로젝트 문맥을 유지한 채 보존된 터미널 세션으로 돌아갈 수 있습니다.

원격 개발을 한눈에

• 여러 SSH 호스트를 저장하고 신뢰하기 전에 호스트 키 지문을 확인합니다.
• 기존 SSH 개인 키를 가져오거나 일회용 서버 암호로 키 접근을 초기화합니다.
• 절대 경로로 원격 Git 저장소 또는 일반 작업공간을 추가합니다.
• 선택한 호스트의 worktree, 브랜치, 최근 커밋을 확인합니다.

문맥을 유지하는 터미널

• 호스트, 프로젝트 또는 worktree용 기본 SSH 터미널을 엽니다.
• tmux를 사용할 수 있으면 결정적 식별자를 가진 프로젝트 터미널을 만들거나 다시 연결합니다.
• 터미널 기록을 정리하고 연결이 끊긴 세션을 재연결하거나 명시적으로 닫고 삭제합니다.
• 대화형 터미널이 활성 상태인 동안 진행 중인 Android 알림으로 상태를 표시합니다.

실용적인 SSH 도구

• 로컬 SSH 포트 포워드를 저장하고 기기 전용 또는 LAN 바인딩을 선택합니다.
• 프로젝트를 열기 전에 연결 진단을 실행합니다.
• 별도로 설치된 Termux 앱에서 작업공간 세션을 열 수 있습니다.
• 터미널 색상, 글자 크기, 맞춤 방식과 모바일 입력용 추가 키를 설정합니다.

Hobgoblin은 SSH 서버, 클라우드 계정, 호스팅 Git 서비스 또는 원격 머신을 제공하지 않습니다. 사용자가 접속 가능한 SSH 호스트, 자격 증명과 원격 프로젝트 경로를 준비해야 합니다. 저장소 기능에는 Git이 필요하며 tmux와 Termux 연동은 선택 사항입니다.

광고 없음. 분석 SDK 없음. Hobgoblin 계정 없음.
