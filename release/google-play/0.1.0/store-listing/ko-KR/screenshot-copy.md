# 한국어 스크린샷 순서

기기 프레임이나 추가 홍보 문구 없이 실제 영어 앱 UI를 업로드합니다. 완료된 각 기기 유형에 같은 순서를 사용합니다.

| 순서 | 파일 | 전달 내용 | 대체 텍스트 |
| ---: | --- | --- | --- |
| 1 | `01-settings.png` | SSH 안정성을 조정하고 앱에서 개인정보처리방침을 엽니다. | keepalive 설정과 개인정보처리방침 링크를 보여 주는 Hobgoblin 설정 화면. |
| 2 | `02-projects.png` | 원격 Git 프로젝트를 올바른 호스트와 연결합니다. | 검토용 호스트의 안전한 원격 Git 프로젝트를 보여 주는 Projects 탭. |
| 3 | `03-worktrees.png` | 브랜치, worktree와 커밋을 원격으로 확인합니다. | 검토용 저장소의 worktree와 저장소 문맥을 보여 주는 화면. |
| 4 | `04-terminal.png` | 프로젝트 문맥을 유지한 SSH 터미널에서 작업합니다. | 민감하지 않은 검토 명령과 출력을 보여 주는 활성 SSH 터미널. |
| 5 | `05-terminals.png` | 필요할 때 보존된 터미널 세션으로 돌아갑니다. | 재연결, 닫기, 삭제 동작이 있는 보존 세션을 보여 주는 Terminals 탭. |

`03-worktrees.png`에서는 로컬 데모 사용자 이름과 주소 영역만 흐리게 처리했습니다. 제품 UI나 기능 상태를 조작하지 않았습니다.
