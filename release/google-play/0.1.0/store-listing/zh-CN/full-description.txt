Hobgoblin 是为开发者设计的 Android 工作区，让您安全访问自己的远程开发主机。

直接连接您控制的 SSH 主机，集中管理远程 Git 项目与工作树，并在返回保留终端时继续使用原来的项目上下文。

远程开发一目了然

• 保存多个 SSH 主机，并在信任前核对主机密钥指纹。
• 导入现有 SSH 私钥，或使用一次性服务器密码初始化密钥访问。
• 通过绝对路径添加远程 Git 仓库或普通工作区。
• 查看所选主机上的工作树、分支和近期提交。

保留上下文的终端

• 为主机、项目或工作树打开原生 SSH 终端。
• 在远程主机安装 tmux 时，创建或重新连接具有确定身份的项目终端。
• 集中管理终端记录，重连断开的会话，或明确关闭和删除终端。
• 交互式终端保持活动时，通过 Android 持续通知显示状态。

实用 SSH 工具

• 保存本地 SSH 端口转发，并选择仅本机或局域网绑定。
• 打开项目前先运行连接诊断。
• 可选择在单独安装的 Termux 应用中打开工作区会话。
• 调整终端颜色、字号、适配方式和移动输入扩展按键。

Hobgoblin 不提供 SSH 服务器、云账户、托管 Git 服务或远程主机。您需要自备可访问的 SSH 主机、凭据和远程项目路径。仓库功能需要 Git；tmux 与 Termux 集成为可选功能。

无广告，无分析 SDK，无 Hobgoblin 账户。
