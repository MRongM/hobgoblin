# Google Play 数据安全表单

## 推荐总答案

对“此应用是否收集或分享任何必填用户数据类型？”回答：**否**。

## 依据

Google Play 将“收集”定义为把用户数据传出设备，但明确排除两类与本应用有关的情况：

1. 只在设备上访问和处理、未传出设备的数据。
2. 端到端加密后传输，且开发者和中间方无法读取、只有发送方与接收方拥有所需密钥的数据。

Hobgoblin 的实际边界为：

- 主机配置、远程路径、可信指纹、终端记录、偏好和加密私钥保存在设备的应用私有存储中，不发送给 MRongM。
- SSH 数据直接在用户设备与用户选择的服务器之间传输，由 SSH 加密；MRongM 不运营中转或应用后端。
- 临时服务器密码只用于一次 SSH 公钥初始化尝试，不持久化，也不发送给 MRongM。
- 应用没有广告、分析、遥测、崩溃报告或云同步 SDK。

Termux 是用户主动选择的设备内第三方应用。直接打开 Termux 时，Hobgoblin 可能把 SSH 命令和所选私钥材料交给 Termux 以完成该次明确操作；复制命令时会写入 Android 剪贴板。Google Play 对用户发起且用户合理预期的数据传输提供“分享”披露例外，但该行为仍必须在隐私政策中明确说明，本资料已经完成该说明。

## 表单填写

1. 是否收集或分享必填用户数据类型：**否**。
2. 提供隐私政策：**是**，使用 <https://mrongm.github.io/hobgoblin/privacy/>。
3. 若 Console 在选择“否”后不显示逐类问题，不要为了展示安全徽章而虚构数据类型。
4. 若 Console 因政策或问卷版本要求继续回答加密问题：所有由应用发起的远程会话数据均通过 SSH 加密传输，回答 **是**。
5. 若 Console 询问删除请求机制：MRongM 不持有服务器端应用数据；用户可在应用内删除记录，并可通过 Android 清除存储或卸载删除全部剩余本地数据。不要声称存在未实现的服务器端删除接口。

## 上传前复核

- 使用 Play Console SDK 索引复核 `sshj`、AndroidX Compose 和 Termux terminal library 的当前数据行为。
- 检查最终 AAB 的合并清单和依赖树，确认没有构建变体引入分析或广告 SDK。
- 确认隐私政策、数据安全答案与实际 Termux 传输、通知内容和本地保留行为一致。
- 任何后续遥测、云同步、崩溃收集或开发者后端都会改变本答案，必须在发布相应版本前更新表单和隐私政策。
